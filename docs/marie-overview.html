마리에 (Marié)

웨딩업계 구인구직 플랫폼 · 플랫폼 소개서 · 2026.04

1. 서비스 개요

마리에(Marié)는 대한민국 웨딩 산업 종사자들을 위한 구인구직·프로필 플랫폼입니다. 흩어져 있던 예식장·드레스·스튜디오·메이크업·플래너·도우미·사회자·축가 등의 업종이 한 공간에서 서로를 발견하고, 인력을 구하고, 업무를 협업할 수 있도록 연결합니다.

한 줄 정의

"웨딩업계의 구인구직 · 채용 공고 · 커뮤니티를 하나로 묶은 전문 네트워크"

플랫폼 성격

  • 웨딩업계 전문 플랫폼 — 일반 소비자(신랑신부)가 아닌, 웨딩 업계 종사자 간 교류를 위한 서비스
  • 한국어 기반 — 국내 웨딩 산업 종사자를 대상으로 한 완전 한글화 UI
  • 자체 호스팅 인프라 — 데이터 주권 확보, 빠른 응답속도

2. 해결하려는 문제

기존 업계 페인 포인트 마리에의 해결 방식
인맥/카톡방 의존적인 구인 구조 공개 게시판을 통한 투명한 채용 공고
업체 정보가 흩어져 있어 검증 어려움 업체 디렉토리 · 포트폴리오 갤러리 · 연락처 통합 제공
프리랜서(도우미·사회자·축가)의 일감 수급 불안정 채용 공고 게시판으로 지역·업종·고용형태별 매칭
업계 정보·트렌드·소식 공유 채널 부재 커뮤니티 · 이벤트&소식 · 관리자 공지 통합 운영

3. 타깃 사용자

마리에는 결혼식을 만드는 모든 종사자를 대상으로 합니다. 개인 프리랜서부터 중소 업체까지 동일한 공간에서 프로필을 갖고 활동합니다.

대상 업종

예식장 · 드레스샵 · 스튜디오 · 메이크업 · 플래너 · 예식 도우미 · 사회자 · 디자이너 · 축가

사용자 유형

  • 웨딩 업체 대표 — 성수기 인력이 부족하여 안정적인 도우미·프리랜서 풀이 필요한 중소 업체 운영자. 채용 공고를 올리고 적합한 업체와 채용/협업을 맺고자 합니다.
  • 프리랜서 종사자 — 사회자, 축가, 예식 도우미 등 개인 활동가. 자신의 프로필을 노출시키고 지역별 일감을 빠르게 확인하고 지원하기를 원합니다.
  • 신규 업체 / 디자이너 — 신생 드레스샵·스튜디오 운영자. 업계 인지도 확보와 채용 전 확인할 프로필 발굴이 필요합니다. 포트폴리오 갤러리로 업체 역량을 노출합니다.
  • 업계 실무자 — 플래너, 도우미 등 현장 실무자. 업계 동향·이벤트·다른 업체의 후기 등을 커뮤니티에서 공유하고 소통합니다.

4. 핵심 기능

  1. 채용 공고 — 업종·지역·고용형태별 다중 필터, 마감일 D-day 표시, 대표 이미지 및 리치텍스트 상세 설명, 마감 알림 뱃지.
  2. 업체 디렉토리 — 업종·지역별 업체 탐색. 로고, 업체 소개, 규모, 설립연도, 주소, 포트폴리오 갤러리, 연락처·웹사이트 바로연결.
  3. 커뮤니티 — 자유게시판 형식. 좋아요, 댓글, 정렬(최신/인기), 탭/검색 필터. 이미지 첨부 가능한 리치텍스트 에디터.
  4. 이벤트 & 소식 — 박람회·세미나·업계 공지 등 관리자가 등록하는 소식. 이벤트 유형별 필터, 상세 페이지 제공.
  5. 마이페이지 / 프로필 — 내 업체 정보 관리, 디렉토리 등록 토글, 포트폴리오 갤러리, 내가 쓴 공고/글 관리.
  6. 간편 로그인 — 이메일 가입 + 카카오 OAuth 소셜 로그인. 로그인 상태는 쿠키로 유지되어 새로고침에도 끊김 없음.
  7. 리치텍스트 에디터 — 굵기·크기·정렬·이미지 삽입을 지원하는 자체 contentEditable 에디터. 붙여넣기·드래그앤드롭 이미지 업로드.
  8. 관리자 페이지 — 이벤트/공지 CRUD, 회원 관리, 콘텐츠 관리 등 운영을 위한 별도 백오피스.

5. 서비스가 노리는 효과

  1. 업계 진입장벽 완화 — 인맥이 부족한 신규 종사자도 공개 게시판을 통해 일감을 얻을 수 있습니다.
  2. 업체 홍보 채널 제공 — 개별 홈페이지 없이도 디렉토리 등록만으로 잠재 파트너에게 노출됩니다.
  3. 성수기 인력 매칭 가속 — 지역·업종별 실시간 공고로 채용 리드타임 단축.
  4. 업계 지식·정보 축적 — 커뮤니티를 통한 노하우·후기·이슈 공유 공간 확보.
  5. 신뢰 기반 네트워크 구축 — 프로필·포트폴리오·리뷰가 누적되어 장기적으로 업계 평판 레이어 형성.

7. 차별점

  • 웨딩 산업 특화 — 범용 구인구직 서비스가 아닌, 웨딩 업종·지역·고용형태 체계를 그대로 반영한 전문 UI/UX.
  • 종합 구인구직 허브 — 채용 + 프로필 + 디렉토리 + 커뮤니티 + 이벤트가 하나의 계정/프로필에 통합됩니다.
  • 직관적인 작성 UX — 네이버 글쓰기 스타일의 에디터, 단계별 폼, 업로드 힌트 등 초보자도 한 번에 등록 가능.
  • SSR 기반 빠른 탐색 — 대부분의 페이지가 서버 렌더링되어 초기 로딩이 빠르고, 필터 이동 시 프로그레스바로 반응성 확보.
