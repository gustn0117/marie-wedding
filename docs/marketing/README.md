# 마리에 팩스용 소개서

## 발송 파일

- `마리에-소개.pdf` — 상세 안내 2쪽. 1쪽은 핵심 제안, 2쪽은 실제 이용 순서·지원자 관리·FAQ입니다.
- `마리에-소개-1장요약.pdf` — 팩스 장수를 줄일 때 쓰는 1쪽 요약본입니다. 상세본의 1쪽과 같은 내용입니다.

두 파일 모두 A4이며 컬러·사진·QR 코드 없이도 전달되도록 흑백 대비, 굵은 구획선, 9pt 이상 본문을 기준으로 제작했습니다.

## 문서에 반영한 현재 기능

- 업체 회원의 채용 공고 등록
- 업종·고용형태·지역·급여·경력·마감일 및 구조화된 공고 본문
- 개인 회원의 이력서 선택 지원과 지원 시점 제출본 보관
- 공고별 지원자 상태 관리(접수·검토 중·승인·거절)
- 제출 이력서·연락처 확인과 채용 담당자 전용 비공개 메모
- 현재 채용 공고 등록·지원 무료, 선택형 노출·광고 상품 별도

확인 기준은 `src/features/jobs`, `src/features/applications`, `src/features/resumes`, `src/features/payments`의 현재 구현입니다.

## 다시 생성하기

프로젝트 루트에서 실행합니다.

```bash
node scripts/generate-intro-pdf.mjs
```

생성 원본은 `scripts/generate-intro-pdf.mjs`입니다. Pretendard 1.3.9 정적 폰트 URL을 사용하며, 생성된 PDF에는 사용 글꼴이 부분 포함됩니다.

## 검수 자료

`previews/`에는 150dpi 페이지 미리보기와 저해상도·1비트 흑백 변환을 거친 팩스 가독성 시뮬레이션이 있습니다.

- `detailed-page-1.png`, `detailed-page-2.png` — 상세본 실제 렌더
- `summary-page-1.png` — 1장 요약본 실제 렌더
- `fax-page-1.png`, `fax-page-2.png`, `fax-summary.png` — 팩스 열화 검수본

## 발송 전 확인

PDF에는 `(광고)`, 발신자, 문의·수신거부 안내를 넣었습니다. 문서 표기와 별개로 실제 광고성 팩스 발송은 수신 동의·법령상 허용 근거, 수신거부 처리, 발송 시간 등 운영 요건을 함께 확인해야 합니다.
