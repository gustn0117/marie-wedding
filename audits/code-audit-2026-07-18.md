# 마리에 코드베이스 심층 감사 보고서

- 감사일: 2026-07-18
- 범위: 정확성·널 안전, 인가/RLS/소유권, 데이터 수명주기, 이미지·업로드, 375px 모바일 성장성, 레이스/낙관적 UI, 폼 검증, 캐시·일관성, 외부 연동, 배포·복구
- 방식: 읽기 전용 조사. 코드·설정·DB 데이터는 변경하지 않음
- 배포 기준: Vercel 미사용, Next.js standalone Docker 셀프호스팅, 기본 `WEB_CONCURRENCY=4`, nginx blue/green, self-hosted Supabase
- 제외: 결제 미사용, `ADMIN_PW` 의도적 유지

## 실데이터 선행 확인

- PostgreSQL 15.8
- 현재 주요 행수: `profiles=3`, `jobs=3`, `resumes=3`, `posts=2`, `comments=2`, `job_view_dedup=2`, `applications=1`, `auth.users=25`; 나머지 주요 앱 테이블은 0행
- 실제 storage: `verifications=117개/255,702,324 bytes`, `avatars=30개`, `job-images=34개`, `resume-files=2개`
- `verifications`는 공유 Supabase bucket이므로 117개가 모두 Marie 소유인지는 불확실하다. 다만 anon 권한 노출 자체는 운영 정책과 실제 응답으로 확인했다.
- 실제 인덱스와 `EXPLAIN ANALYZE/BUFFERS`를 수집했다. 지역 wildcard 검색과 exact count는 현재 3행에서 약 0.1ms지만 `Seq Scan`이었고, 메시지 요약은 `(conversation_id, created_at)` bitmap scan 후 global sort, unread 조회는 partial index 없이 후필터했다.

- anon 임의 profile purge: 최신 migration의 함수 `EXECUTE` revoke로 차단됨
- 이력서 PII 잔존: 최신 redaction trigger가 방어함
